# 残業トラッカー（Overtime Tracker）

年度（4月1日〜翌年3月31日）単位で日々の残業（実績・予測）を入力し、月次集計・21日締め集計・経過率・営業日数・年間合計・残業ペース配分を算出し、社内の残業上限ルールに対する警告を表示する、ローカル動作のアプリです。ビルド不要・外部ネットワーク非依存で動きます。

## 使い方（公開URL）

ブラウザで以下を開くだけです（HTTPS配信のためそのまま動作します）:

**https://setaniguch.github.io/overtime-tracker/**

## 画面

- **📊 メイン画面**: 残業ペース配分・上限警告・月次集計表・年間合計を表示。「集計CSV出力」あり。
- **✍ 入力画面**: 月ごとに日次の実績・予測・備考を入力。「CSV取込」「入力CSV出力」あり。
- 上部の共有バーで年度の選択・作成、基準日（本日）の変更ができます。

## データについて

- 入力データはお使いのブラウザの **localStorage** に自動保存されます（変更後2秒以内）。
- 同じブラウザ・同じURLで開けば、次回も自動で復元されます。
- 別のPCやブラウザへ移すときは「入力CSV出力」でCSVに書き出し、移行先で「CSV取込」してください。
- サーバーには一切データを送信しません（ローカル完結）。

## ローカルで動かす場合

ESモジュールを使うため、`index.html` をダブルクリック（`file://`）では動きません。ローカルサーバー経由で開いてください。

- Node がある場合: フォルダ内で `npx serve` を実行し、表示されたURLを開く
- Python がある場合: `python -m http.server 3000` → `http://localhost:3000`
- VS Code の場合: 拡張機能「Live Server」で `index.html` を開く

## 開発

```bash
npm install     # テスト用の依存を取得
npm test        # Vitest + fast-check による全テストを実行
```

- 実行に依存ライブラリは不要（バニラ JavaScript + HTML + CSS）。
- `src/core/` … 副作用のないドメイン層（集計・判定・CSV変換）
- `src/adapters/` … UI・永続化・ファイルI/O（副作用を担う層）
